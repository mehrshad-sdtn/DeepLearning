# DeepLearning
### A Deep Neural Networks Playground

In this repository I:
1) play around with neural networks and run interesting experiments using them
2) re-implement prominent deep learning papers
3) store any deep learning related code that I write

The repository includes three main directories: [Playground](https://github.com/mehrshad-sdtn/DeepLearning/tree/master/Playground), [Pytorch](https://github.com/mehrshad-sdtn/DeepLearning/tree/master/PyTorch), and [Papers](https://github.com/mehrshad-sdtn/DeepLearning/tree/master/Papers); <br>
- Playground directory contains interesting deep learning experiments and side projects <br>
- Pytorch directory contains notebooks of my practice codes <br>
- Papers directory contains the implementations of some prominent deep learning papers <br>
